# Introduction - API Centric Integration

<br>![](/exercises/ex0/images/ex0_01.png)


🌐 SAP Integration Suite provides a unified environment for connecting applications, data, and business processes across cloud and on-premise landscapes. As organizations increasingly expose business capabilities through APIs, 🧩 **APIs are no longer just interfaces to backend systems**—they have become a fundamental building block for enterprise integration.

**API-centric integration brings API design and integration capabilities together** in a unified experience. It enables developers to create APIs that directly connect to backend systems, mediate and transform requests and responses, compose multiple services, and expose simplified interfaces to API consumers. With this approach, developers can build APIs ranging from simple managed endpoints to rich integration scenarios while applying security, traffic management, and lifecycle governance as part of the same development experience.

🚀**Hands-on Session**

In this hands-on session, you will take the role of an API product team in an enterprise that wants to make a business capability available as a managed API. Instead of building point-to-point connections or sharing raw backend endpoints, you will design, deploy, secure, publish, and consume an API artifact using SAP Integration Suite.

🧩**What You Will Do**

You will start by enabling and verifying the Integration Cell runtime, which provides the runtime environment for your API artifacts. You will then create your first API artifact in multiple ways: from an OpenAPI specification or URL, through an API Provider, and by reusing an existing API definition. This will show you how API-centric integration supports different starting points—whether you begin with a specification, an existing backend system, or an already-published API.

Next, you will make the API production-ready. You will apply security policies, test the protected endpoint, and use monitoring capabilities to understand how the API is being called. You will then package the API artifact into an API product, publish it through the Developer Hub, and experience the consumer perspective: discovering the product, subscribing to it, and consuming the API. Finally, you will explore modern API analytics to understand usage, performance, and consumption patterns.

🏁 **What You Will Have at the End**

By the end of the session, you will have a complete, working API lifecycle:

 - A deployed API artifact running on the Integration Cell runtime
 - Multiple practical ways to create API artifacts from specifications, providers, and reusable APIs
 - A secured API with policies applied and verified through testing
 - Operational insight through API monitoring
 - A published API product that can be discovered and subscribed to in the Developer Hub
 - A consumed API endpoint tested with Bruno
 - Visibility into API usage through analytics

More importantly, you will understand how the responsibilities shift across the API lifecycle: API designers and developers create and expose capabilities, platform and security teams govern access and policies, and API consumers discover and use products through a self-service experience. This end-to-end perspective is the foundation for building scalable, governed, and consumption-ready API ecosystems with SAP Integration Suite.
