# IN162 - Building API-Centric Integration Flows with SAP Integration Suite.

## Description

This repository contains the material for the SAP TechEd 2026 session called Session ID - 
IN162 - Building API-Centric Integration Flows with SAP Integration Suite.

## Overview


🔌 This session explores **the API-centric paradigm** and its role in designing, exposing, securing, and operating modern integration services. 🔄 **It combines conceptual guidance with hands-on exercises** to provide practical experience across the complete API lifecycle.

The session begins with an introduction to API-centric integration and the underlying principles of API design. 🛠️ **Participants will then design and deploy an API artifact** using three different approaches. Subsequent hands-on exercises focus on essential operational capabilities, including 🔒 **API security, testing, monitoring, analytics, consumption, and runtime operations.**

## Requirements

There are no dedicated requirement for this session. **You will be able to execute the exercises by just following the steps & descriptions** even if you do not have any experience with SAP Integration Suite.

However, you will be able to derive more value from this session, if you have some knowledge and understanding of API management and cloud integration which are key capabilities of SAP Integration Suite.
